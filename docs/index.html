ระบบ Thai Lottery Analytics ได้รับการพัฒนาขึ้นโดยมีเป้าหมายเพื่อเป็นเครื่องมือประมวลผลข้อมูลทางสถิติและแบบจำลองวิทยาศาสตร์ข้อมูล (Data Science) ผลสลากกินแบ่งรัฐบาลแต่ละงวดเป็นปรากฏการณ์สุ่มแบบอิสระ (Independent and Identically Distributed Random Variables)

แบบจำลองทางสถิติไม่สามารถทดแทนการสุ่มได้ และผลคะแนนความน่าจะเป็น (Confidence Score) ไม่ใช่คำสัญญาหรือการรับประกันผลรางวัลใดๆ ทั้งสิ้น ผู้ใช้งานควรใช้วิจารณญาณและความรับผิดชอบในการตัดสินใจทางการเงิน
สถาปัตยกรรมและการทำงานของระบบ

ระบบใช้รูปแบบ Pre-computed Static Site Architecture ดำเนินการผ่าน GitHub Actions ทุกวันที่ 1 และ 16 ของเดือน:

  1. Data Ingestion: รวบรวมข้อมูลด้วยสถาปัตยกรรม Fallback 3 แหล่ง (myhora.com → sanook.com → glo.or.th) เพื่อความต่อเนื่องของข้อมูล
  2. Feature Engineering: คำนวณความถี่, Gap Analysis (ระยะห่างการไม่ออก), คู่/คี่, สูง/ต่ำ, ข้างขึ้นข้างแรม และ Pattern รายเดือน
  3. Machine Learning Ensemble:
    • Frequency Model: คำนวณการแจกแจงความถี่ถ่วงน้ำหนักตามประวัติศาสตร์
    • ARIMA (2,1,2): ตรวจจับแนวโน้มความถี่และ Autocorrelation ตามลำดับเวลา
    • Prophet: วิเคราะห์ปัจจัยฤดูกาลและผลกระทบของช่วงวัน/เดือน
    • LSTM Deep Learning: โครงข่ายประสาทเทียมตรวจจับรูปแบบลำดับตัวเลข 24 งวดย้อนหลัง
  4. Walk-Forward Backtesting: ประเมินความแม่นยำย้อนหลังแบบจำลองจริงทีละงวด เพื่อนำค่า Hit-Rate มากำหนดน้ำหนัก Dynamic Weight ให้กับ Ensemble
  5. Automated Export: บันทึกผลลัพธ์ลง JSON/CSV และแสดงผลผ่าน GitHub Pages ทันทีโดยไม่ต้องมีค่าใช้จ่ายเซิร์ฟเวอร์
